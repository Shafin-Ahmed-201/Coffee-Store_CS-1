# ☕ Coffee Shop Landing Page

A simple and visually appealing coffee shop landing page built using **HTML5 and CSS3**. 
The website presents a coffee brand with sections for popular coffee items, opening hours, the brand story, and a promotional banner.

## 📌 Project Overview

This project is a static coffee shop landing page designed to provide visitors with information about the coffee shop and its popular products.

The website includes a hero section, coffee shop story, popular coffee items, opening hours, and a promotional section highlighting the shop's availability.

The main goal of this project was to practice building a structured webpage using **semantic HTML** and styling it with **modern CSS layouts such as Flexbox, CSS Grid, positioning, gradients, and background images**.

---

## 🚀 Features

- Coffee shop navigation bar
- Hero section with background image and dark overlay
- "Order Now" call-to-action button
- "Our Story" section with image and description
- Popular coffee products section
- Product cards for different coffee types
- Coffee prices displayed on product cards
- Opening hours table
- Promotional banner section
- "24/7 Open" circular badge
- Hover effects on buttons
- Custom favicon
- Clean and simple coffee-themed design

---

## 🛠️ Technologies Used

The following technologies were used to build this project:

- **HTML5** — Used to create the structure and content of the webpage.
- **CSS3** — Used for styling, layouts, colors, spacing, backgrounds, and visual effects.
- **CSS Flexbox** — Used for navigation and different content layouts.
- **CSS Grid** — Used to create the popular coffee product card layout.
- **CSS Positioning** — Used to place promotional content over the footer image.
- **CSS Linear Gradient** — Used to create a dark overlay over the hero background image.
